User Guide
==========

Welcome to the User Guide for **splineops**, a library designed to perform advanced operations on spline geometries. This guide provides detailed explanations, tutorials, and examples for using the modules available in `splineops`.

Overview
--------

`splineops` consists of several modules that enable operations such as resizing and rotating splines. This guide covers:

- Conceptual explanations of each module.
- Practical examples to get started.
- Tips for combining multiple modules to solve complex problems.
