API Reference
=============

The following table provides an overview of the SplineOps modules:

.. list-table::
   :widths: 25 75
   :header-rows: 1

   * - **Module**
     - **Description**
   * - :ref:`TensorSpline <api-tensorspline>`
     - Core interpolation class for N-D data.

     - Resize using splines or LS/Oblique projection.
   * - :ref:`Rotate <api-rotate>`
